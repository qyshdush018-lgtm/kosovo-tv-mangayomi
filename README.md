# Kosovo TV - Mangayomi Extension

Mangayomi extension for Kosovo television channels.

## Installation

Add this repository to Mangayomi:

https://raw.githubusercontent.com/qyshdush018-lgtm/kosovo-tv-mangayomi/main/index.json

## Channels

Provides available Kosovo television channels through publicly available streams.

## Disclaimer

This extension does not host video content. Stream availability depends on the respective stream providers.
